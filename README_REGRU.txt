CRM-STARCOMP — установка на хостинг reg.ru
==========================================

Что лежит в архиве
------------------
index.html   — сама CRM (вся программа в одном файле)
api.php      — передаточник между страницей и базой MySQL
db.php       — настройки подключения к базе ( НАДО ЗАПОЛНИТЬ )
install.php  — одноразовый установщик ( ПОСЛЕ УСТАНОВКИ УДАЛИТЬ )

Порядок установки
-----------------

1. В панели reg.ru: Хостинг → Базы данных
   Создайте базу MySQL и пользователя к ней. Запишите:
     имя базы, имя пользователя, пароль, адрес сервера БД.
   Адрес сервера часто "localhost", но у reg.ru бывает вида
   mysqlXXXX.hosting.reg.ru — смотрите в панели.

2. Откройте файл db.php в любом текстовом редакторе (Блокнот)
   и замените три пустых/примерных значения:
     $DB_HOST = '...';  — адрес сервера БД
     $DB_NAME = '...';  — имя базы
     $DB_USER = '...';  — пользователь базы
     $DB_PASS = '...';  — пароль пользователя
   Сохраните файл.

3. Загрузите ВСЕ ЧЕТЫРЕ файла через Файловый менеджер reg.ru
   в папку сайта crm.star-comp.ru (обычно /crm.star-comp.ru/
   или /public_html/crm/). Файлы должны лежать в одной папке.

4. Откройте в браузере: https://crm.star-comp.ru/install.php
   Появится поле «Код установки». Введите: starcomp2026
   Должно появиться сообщение "Готово!". Это создаст таблицы,
   загрузит 5 текущих заказов, 19 деталей и двух пользователей —
   admin и igor. Пароли для них заданы в файле install.php
   (строки $users в начале файла).

5. ОБЯЗАТЕЛЬНО удалите install.php с хостинга через Файловый
   менеджер. Иначе любой сможет сбросить ваши данные заново.

   Если при установке вы видели сообщение "There is no active
   transaction" — не пугайтесь: таблицы и данные уже загружены,
   это была только ошибка в финальном сообщении установщика.
   В этой сборке она исправлена. Повторно запускать установку
   не нужно — просто удалите install.php.

6. Откройте https://crm.star-comp.ru — должно появиться окно
   входа CRM-STARCOMP. Войдите под admin или igor.

7. Настройте SSL (Let's Encrypt) в панели reg.ru и включите
   автоматический переход с http на https.

8. Удалите также этот файл README_REGRU.txt с хостинга —
   он вам больше не нужен, а лишние файлы на сайте ни к чему.

Пароли
------
Старые пароли Supabase перенести технически нельзя, поэтому
они задаются заново в install.php. Изменить их потом можно
в phpMyAdmin: таблица users, поле password_hash.

Что есть в этой сборке
----------------------
• Заказы, архив, «Железо».
• Вкладка «Склад» (только admin): позиции, серийные номера с защитой
  от дублей, гарантия, поставщик, чеки и файлы, поиск, архив позиций.
• Вкладка «Дашборд» (только admin): закрытые заказы и прибыль по MX
  с выбором месяца. Отказы в статистику не идут.
• Статус «Отказ» — заказ уходит в архив.
• Для igor архив показывает заказы только за последние 10 дней;
  вкладки «Склад» и «Дашборд» скрыты.
• Кнопка «Сохранить» во всех формах защищена от повторного нажатия.

Дополнительные данные (склад и даты архива) хранятся в таблице settings
под ключами stock_items и archive_dates — отдельные таблицы не нужны.
Поле v в таблице settings обязательно должно быть LONGTEXT (не VARCHAR),
иначе позиции склада туда не влезают. В новой сборке это уже исправлено.

Дозагрузка архива и склада
--------------------------
Если после установки архив и склад пусты (выгрузка была от 19.11,
когда архивных заказов и склада ещё не было), сделайте один раз:
  1. Загрузите файл import_data.php в ту же папку сайта.
  2. Откройте https://crm.star-comp.ru/import_data.php
  3. Введите код starcomp2026 и нажмите «Импортировать».
  4. Удалите import_data.php с хостинга.
Импорт загрузит полную выгрузку от 19.11: 5 заказов (4 из них в архиве),
30 деталей «Железо» и 29 позиций склада (2 в архиве, с чеком).
Записи с теми же id обновятся, новые добавятся. Повторный запуск безопасен.

Важно
-----
Supabase можно не удалять сразу — пусть поработает параллельно
несколько дней. Старый адрес GitHub Pages тоже продолжит работать.
Данные при переносе НЕ теряются: выгрузка сделана из Supabase 19.11.2026.
