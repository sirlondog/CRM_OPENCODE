CRM-STARCOMP — установка на хостинг reg.ru
==========================================

Что лежит в архиве
------------------
index.html   — сама CRM (вся программа в одном файле)
api.php      — передаточник между страницей и базой MySQL
db.php       — настройки подключения к базе ( НАДО ЗАПОЛНИТЬ )
install.php  — одноразовый установщик ( ПОСЛЕ УСТАНОВКИ УДАЛИТЬ )

Порядок установки
-----------------

1. В панели reg.ru: Хостинг → Базы данных
   Создайте базу MySQL и пользователя к ней. Запишите:
     имя базы, имя пользователя, пароль, адрес сервера БД.
   Адрес сервера часто "localhost", но у reg.ru бывает вида
   mysqlXXXX.hosting.reg.ru — смотрите в панели.

2. Откройте файл db.php в любом текстовом редакторе (Блокнот)
   и замените три пустых/примерных значения:
     $DB_HOST = '...';  — адрес сервера БД
     $DB_NAME = '...';  — имя базы
     $DB_USER = '...';  — пользователь базы
     $DB_PASS = '...';  — пароль пользователя
   Сохраните файл.

3. Загрузите ВСЕ ЧЕТЫРЕ файла через Файловый менеджер reg.ru
   в папку сайта crm.star-comp.ru (обычно /crm.star-comp.ru/
   или /public_html/crm/). Файлы должны лежать в одной папке.

4. Откройте в браузере: https://crm.star-comp.ru/install.php
   Должно появиться "Установка CRM-STARCOMP" и сообщение
   "Готово!". Это создаст таблицы, загрузит 5 текущих заказов,
   19 деталей и двух пользователей — admin и igor.
   Пароли для них задаются в файле install.php перед загрузкой
   на хостинг (строки $users в начале файла).

5. ОБЯЗАТЕЛЬНО удалите install.php с хостинга через Файловый
   менеджер. Иначе любой сможет сбросить ваши данные заново.

6. Откройте https://crm.star-comp.ru — должно появиться окно
   входа CRM-STARCOMP. Войдите под admin или igor.

7. Настройте SSL (Let's Encrypt) в панели reg.ru и включите
   автоматический переход с http на https.

8. Удалите также этот файл README_REGRU.txt с хостинга —
   он вам больше не нужен, а лишние файлы на сайте ни к чему.

Пароли
------
Старые пароли Supabase перенести технически нельзя, поэтому
они задаются заново в install.php. Изменить их потом можно
в phpMyAdmin: таблица users, поле password_hash.
