КАК ДЕЛАТЬ БЭКАП БАЗЫ CRM-STARCOMP
==================================

Способ 1 (самый простой) — кнопка на сайте
------------------------------------------
1. Один раз загрузите файл backup.php в ту же папку сайта, где лежит
   index.html (рядом с api.php и db.php).
2. Откройте в браузере: https://crm.star-comp.ru/backup.php
3. Введите код: starcomp2026
4. Нажмите «Скачать SQL (восстановление)» — файл crm-backup-ДАТА.sql
   сохранится у вас на компьютере. Это полный бэкап базы.
   Кнопка «Скачать JSON (перенос)» нужна только для переноса данных
   в другую CRM.

Файл backup.php можно оставить на хостинге — без кода он ничего
не показывает. Если хотите, поменяйте код в этом файле на свой.

Куда сохранять
--------------
Рекомендую папку D:\star-comp_cl-backups\ (она уже есть). Раз в неделю
достаточно; перед любыми изменениями на сайте — обязательно.

Способ 2 — панель reg.ru
------------------------
Хостинг → Резервные копии: включите автоматические копии (если есть
такая услуга). Это дополнительная страховка, но файл от backup.php
всё равно стоит скачивать себе на компьютер.

Как восстановиться
------------------
В phpMyAdmin выберите базу → Импорт → выберите файл .sql → Вперёд.
ВНИМАНИЕ: импорт перезапишет текущие таблицы — сначала сделайте
свежий бэкап.
