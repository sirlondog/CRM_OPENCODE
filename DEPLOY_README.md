# Как обновляется CRM после правок

## Один раз настроить (5 минут)

### 1. Узнайте данные FTP в reg.ru

Личный кабинет reg.ru → ваш хостинг → вкладка **Доступы** (или в ISPmanager → **Доступы / Пользователи FTP**). Там будут:

- **Сервер FTP** — адрес вида `ftp.star-comp.ru`, `serverXXX.hosting.reg.ru` или IP;
- **Логин** — например `u2959673` или отдельный FTP-пользователь;
- **Пароль**;
- **Порт** — обычно `21`.

Если FTP-пользователя нет, создайте его в ISPmanager: **Доступы → Пользователи FTP → Создать**, укажите корневую папку сайта `crm.star-comp.ru`.

### 2. Добавьте данные в GitHub

Откройте https://github.com/sirlondog/CRM_OPENCODE → **Settings** → слева **Secrets and variables** → **Actions** → кнопка **New repository secret**. Добавьте 5 секретов:

| Имя секрета | Что вписать |
|---|---|
| `FTP_SERVER` | адрес FTP-сервера |
| `FTP_USERNAME` | логин FTP |
| `FTP_PASSWORD` | пароль FTP |
| `FTP_PORT` | `21` |
| `FTP_SERVER_DIR` | `/` — если FTP сразу открывает папку сайта; иначе `/crm.star-comp.ru/` |

Проверить `FTP_SERVER_DIR` просто: подключитесь FTP-клиентом (например FileZilla) — если сразу видны `index.html` и `api.php`, ставьте `/`. Если сначала видите папки сайтов — ставьте `/crm.star-comp.ru/`.

### 3. Всё

Больше ничего делать не надо.

## Как работать каждый день

1. Вы говорите, что нужно поменять в CRM.
2. Я правлю файлы локально, проверяю и делаю `git push` в ветку `regru`.
3. Через 1–2 минуты GitHub сам загружает изменённые файлы на хостинг.
4. Вы обновляете страницу `https://crm.star-comp.ru` (если не подхватилось — `Ctrl+F5`) и проверяете.

Прогресс загрузки видно тут: https://github.com/sirlondog/CRM_OPENCODE/actions

## Что НЕ загружается автоматически

- **db.php** — там пароль от базы. Он лежит на сервере с момента первой установки и не трогается. Если поменяете пароль базы в reg.ru — скажите мне, я подготовлю новый `db.php`, и вы загрузите его вручную один раз.
- **install.php** — нужен только для первичной установки. После установки его надо удалить с сервера и больше не загружать.
- **README_REGRU.txt** и этот файл — инструкции, на сайт не нужны.

## Если автоматизация не заработает

Резервный путь — загрузить файл вручную через Файловый менеджер reg.ru или FTP-клиент:

1. Скачать нужный файл из ветки `regru` на GitHub (кнопка «Скачать» у файла).
2. Загрузить в корень сайта `crm.star-comp.ru`, заменив старый.
3. Обновить страницу с `Ctrl+F5`.

Обычно меняется только `index.html`. Файлы `api.php`, `db.php`, `install.php` правятся редко.
